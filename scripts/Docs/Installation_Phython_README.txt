HOW TO RUN THE CODE

HOW TO CREATE AOI SHAPEFILE IN GEE?
Step1: Select AOI from GEE as geometry using required coordinates and Export as Shapefile using code.


IN PYCHARM ENVIRONMENT->
Step1: Copy the shapefiles(6 in total), and paste to AOI folder in Pycharm Project.
Step2: Change name of shapefile in parameters.json accordingly. 
step3: Right click on utilities.py and click run.
Step4: Right click on GEE_Funcs.py and run.
Step5: Finally right click on Fusion_GEE and run.

AGAIN IN GEE:
Step1: After image is exported click on the image in Tasks tab of GEE (top-right), click on view asset, click import, click show on map, centre map on record.
